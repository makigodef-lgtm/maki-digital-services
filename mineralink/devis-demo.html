Préparer un devis et simuler son règlement

Démonstration uniquement. Aucun encaissement, facture fiscale, compte marchand, paiement CinetPay ou vérification bancaire n'est effectué. Ne demandez jamais de code PIN ni d'identifiants Mobile Money.

Le document est généré uniquement dans ce navigateur et n'est pas enregistré sur un serveur. Un devis accepté n'est pas une preuve de paiement.

Passage au paiement réel

Le paiement réel exigera une structure légalement admissible, un compte marchand approuvé, un serveur sécurisé pour les clés API et la vérification des notifications du prestataire. Aucun bouton de paiement réel n'est proposé ici.
