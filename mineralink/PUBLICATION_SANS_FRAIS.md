# MineraLink RDC · publication sans frais (11 novembre 2026)

## Déjà en place
- Application web progressive (PWA) et vitrine commerciale bilingue stockées dans le dépôt GitHub public.
- GitHub Actions a publié avec succès le site statique. Une vérification HTTP indépendante reste à faire depuis un navigateur externe.
- Installation depuis le site sur Android et iPhone, sans boutique d'applications ni frais développeur.
- Offre double face : acheteurs et fournisseurs peuvent demander séparément une prestation facultative sur devis. Aucune transaction ou versement marchand n'est activé.
- Pas de coordonnées financières ni de passeports publiés dans le dépôt.

## Plateformes gratuites envisageables

### Samsung Galaxy Store
Inscription gratuite et sans frais annuels, selon https://developer.samsung.com/galaxy-store/faq.html .
Conditions restantes : compte Samsung, Seller Portal, statut commercial et **véritable fichier Android signé**.
Portail : https://seller.samsungapps.com/ .
**État : non soumis**, en l'absence d'un compte vendeur vérifié.

### Microsoft Store
Microsoft prévoit une nouvelle procédure de création de compte développeur sans frais pour individus et entreprises : https://learn.microsoft.com/en-us/windows/apps/publish/partner-center/partner-center-developer-account .
Portail : https://storedeveloper.microsoft.com/ .
Pour une PWA : réserver le nom et récupérer le Publisher ID puis créer un package Windows dans PWA Builder : https://learn.microsoft.com/en-us/microsoft-edge/progressive-web-apps/how-to/microsoft-store .
**État : non soumis**, car le compte développeur et l'identité de l'éditeur ne sont pas encore validés.

### Google Play / Apple
Aucune inscription gratuite générale du compte développeur commercial n'est confirmée. Ne payer aucun frais avant la validation commerciale.
La PWA installable fonctionne indépendamment de ces deux boutiques.

## Règles commerciales essentielles
- Les listes d'avis publics et les formulaires de base restent gratuits.
- Achats : service de recherche documentaire ciblée, tarif pilote indicatif à partir de 149 USD, sur devis.
- Fournisseurs : veille ciblée d'appels d'offres, tarif pilote indicatif à partir de 49 USD, sur devis.
- Un paiement sur une partie ne garantit pas un classement favorisé ni l'attribution d'un contrat à un fournisseur.
- Le client doit recevoir un devis, connaître les livrables, les délais et les conditions applicables avant d'accepter.
- Aucun virement automatique réel n'est disponible sans compte marchand vérifié et raccordé à une banque ou un portefeuille commercial.
- Les tarifs et prestations doivent être revus à la lumière des obligations congolaises applicables.
