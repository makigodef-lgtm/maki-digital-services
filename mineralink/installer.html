INSTALLATION GRATUITE · ANDROID ET IPHONE

Installez MineraLink sans boutique d'applications.

Notre application web est conçue pour fonctionner sur votre téléphone comme une application. Aucune carte bancaire et aucun code développeur ne sont nécessaires pour cette installation. Les services de paiement ne sont pas encore activés.

Android

  1. Ouvrez cette page dans Chrome ou un navigateur compatible.
  2. Appuyez sur Installer MineraLink ci-dessous si l'option apparaît.
  3. Sinon, ouvrez le menu ⋮ et choisissez Installer l'application ou Ajouter à l'écran d'accueil.

L'option n'apparaît que lorsque votre navigateur accepte l'installation et que le site est accessible en HTTPS.

iPhone et iPad

  1. Ouvrez le site avec Safari.
  2. Touchez Partager, puis Sur l'écran d'accueil.
  3. Activez Ouvrir comme app web si proposé, puis touchez Ajouter.

Cette installation gratuite ne constitue pas une publication sur l'App Store d'Apple.

MineraLink est en version pilote : vous pouvez préparer une demande de devis, présenter votre activité et comparer des propositions. Aucune opération bancaire réelle n'est effectuée dans cette version.
